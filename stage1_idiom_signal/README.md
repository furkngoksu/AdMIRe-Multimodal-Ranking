# Stage 1 — Idiom Signal Models

Five model variants for binary idiomaticity classification. Each model lives in its own folder with a standalone `train.py`.

## Models

| Folder | Input | Head | Description |
|---|---|---|---|
| `baseline/` | Raw target sentence | MLP (BN+GELU) | Simplest baseline |
| `marked_simple/` | `[LANG] <mwe>tagged</mwe> [MWE]` | Simple (ReLU) | Marked input, simple head |
| `marked_mlp/` | `[LANG] <mwe>tagged</mwe> [MWE]` | MLP (BN+GELU) | Marked input, stronger head |
| `perturbation_mlp/` | `abs(target − perturbation)` diffs | MLP (BN+GELU) | LLM perturbation signals only |
| `fusion_mlp/` | Marked emb + perturbation diffs | MLP (BN+GELU) | Context + perturbation fusion |

## Data

- `data/unique_mwe_target_label_language.csv` — All models read from this CSV.
- `data/matched_records.json` — Pre-matched LLM perturbation records (generated by `prepare_data.py`). Required by `perturbation_mlp` and `fusion_mlp`.

## Setup

Generate matched records (one-time, required for perturbation/fusion models):

```bash
python stage1_idiom_signal/prepare_data.py
```

Run a single model:

```bash
python stage1_idiom_signal/baseline/train.py
python stage1_idiom_signal/marked_simple/train.py
python stage1_idiom_signal/marked_mlp/train.py
python stage1_idiom_signal/perturbation_mlp/train.py
python stage1_idiom_signal/fusion_mlp/train.py
```

Run all models or specific ones:

```bash
python stage1_idiom_signal/run_all_models.py
python stage1_idiom_signal/run_all_models.py baseline perturbation_mlp
```

## Output

Each model writes to its `outputs/` folder:

```
outputs/
├── idiom_signal.pt # Best seed model weights
├── config.json     # Model config + best hyperparameters
└── metrics.json    # Per-seed results + aggregate mean F1
```

## Training Pipeline

- Encoder: `xlm-roberta-base` (frozen, embeddings computed once in-memory)
- Hyperparameter search: Optuna TPE sampler, 30 trials
- Each Optuna trial evaluates across 3 seeds (42, 100, 150) for 30 epochs
- The best hyperparameters are evaluated across 5 seeds (42, 100, 150, 200, 250) for 40 epochs
- Each seed uses best-epoch checkpointing by validation F1
- Selection metric: mean validation F1 across seeds
- Device priority: cuda > mps > cpu
